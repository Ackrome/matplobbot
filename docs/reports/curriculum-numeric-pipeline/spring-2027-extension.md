# Проверенные формы контроля на весну 2027

[Файл для импорта](spring-2027-extension.json) добавляет даты весенних
семестров к 11 действующим привязкам. [Свидетельства сверки](spring-2027-evidence.json)
содержат точные ID, хеши ответов РУЗ и номера строк календарных графиков.
Это подготовленная публикация. Данные в production не применялись.

| Группы | Семестр | Период по графику, включительно | Формы контроля |
|---|---:|---|---|
| ПМ23-1…ПМ23-5 | 8 | 02.02–05.07.2027 | 3 зачёта с оценкой по поимённо указанным видам практики |
| ПМ25-1…ПМ25-6 | 4 | 02.02–28.06.2027 | 13 форм из уже проверенного плана (6 экзаменов, 6 зачётов, 1 курсовой проект) для 12 дисциплин |

14 ноября 2026 года словари РУЗ подтвердили очную форму, 2-й и 4-й курсы и ID
факультета 6 Московского кампуса. Во всех 11 осенних расписаниях присутствуют
родительские расписания семестров 3 и 7 и идентификаторы базовых планов 6088 и
3860. Отдельные занятия могут иметь другие идентификаторы, например в общих
потоках. Весенние запросы вернули HTTP 200 и пустые списки для всех 11 групп.
Поэтому даты и формы здесь **плановые**, а охват будущих названий в РУЗ и даты
конкретных зачётов остаются неизвестными.

## Сверка документов

- [График 2023–2027](https://www.fa.ru/upload/constructor/097/bz23oq9v6en1grnexho4qvh7119g6tnf/KUG.pdf)
  и его [сохранённая страница](group-binding/calendar2023-1.png). В строке 4-го
  курса недели 23–26 — учебная практика, 27–37 — производственная
  практика, 38 — перерыв между практикой и итоговой аттестацией, 39–44 —
  государственная итоговая аттестация. С 45-й недели начинаются летние
  каникулы. На странице 2 [учебного плана 2023](https://www.fa.ru/upload/constructor/773/o1glti47zsriv5zhc7qc6agt7g6gou7x/UP.pdf)
  примечание задаёт зачёт с оценкой для видов практики. Блоки практик и
  отдельные строки Б.2.1.1, Б.2.2.1 и Б.2.2.2 сопоставлены с графиком 4-го курса.
  Не присваиваем тип `exam` государственному экзамену и защите ВКР по пустым
  ячейкам промежуточной аттестации. Не подменяем точные названия практик
  общим названием из расписания.
- [График 2025–2029](https://www.fa.ru/upload/constructor/908/3504j6nh3idpc6elldfzlpvl9klpboe2/KUG_PMiI_25_och.pdf)
  и его [сохранённая страница](group-binding/calendar2025-1.png). В строке 2-го
  курса недели 23–40 включают занятия, 41–43 — промежуточную аттестацию.
  С 44-й недели начинаются каникулы. В [проверенном плане 2025](https://www.fa.ru/upload/constructor/e13/mm7ghxp0y1dumv3ons4kyeey1qy0haj1/uchebnyy-plan-PMO_2025-new.pdf)
  для «Машинного обучения», например, одновременно указаны экзамен и
  курсовой проект в семестре 4. Данные плана сохраняются без правок.

Сайт Финуниверситета во время проверки отвечал HTTP 403. Для сверки
графиков использованы страницы, сохранённые при прошлой загрузке официальных
PDF. Учебные планы скачаны через открытые опубликованные копии Matplobbot,
и их SHA-256 совпали с предыдущей публикацией. Отдельный годовой график,
который мог бы переопределить сроки для этих групп, независимо не сверялся.

их SHA-256, проверка нужных колонок контроля и календаря.

## Импорт после выкладки API

Импорт использует уже опубликованные PDF с указанным SHA-256, поэтому
перекачивать исходники или заменять осенние данные не требуется. Запускайте
скрипт из корня проекта с учётными данными администратора через
`STATS_USER` и `STATS_PASS`. `--base-url` допускает HTTP только на localhost,
по умолчанию `http://127.0.0.1:9583`.

```sh
python scripts/publish_curriculum_bundle.py \
  --extension docs/reports/curriculum-numeric-pipeline/spring-2027-extension.json \
  --output /tmp/curriculum-spring-2027-dry-run.json
```

Проверьте отчёт dry-run и повторите команду с другим именем файла отчёта
и `--apply`. Перед изменением скрипт сохраняет снимок метаданных. На сервере
операция добавляет только новые проверенные строки и периоды, отклоняя
конфликты с существующей публикацией. Повторный запуск не делает записей.

Проверка после импорта. Публичный API для ПМ25-1, «Машинное обучение»,
даты `2027-03-01` должен вернуть `confirmed`, `semester: 4`, экзамен и
курсовой проект. Для ПМ23-1, «Производственная практика: преддипломная
практика», той же даты должен прийти `confirmed`, `semester: 8`, зачёт с
оценкой и ссылка на страницу 2 плана. Эти формы не подтверждают наличие
занятия на выбранную дату. Прежние осенние формы и исходные PDF сохраняются.
