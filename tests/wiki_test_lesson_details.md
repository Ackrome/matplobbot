# test_lesson_details.py

Регрессионные проверки модели карточки занятия и привязки действий.
Класс `LessonDetailsTests` исполняет настоящий JavaScript в Node VM;
`run_model` подготавливает только зависимости модели и общую исходную запись.
`run_schedule_model` исполняет настоящие функции загрузки, фильтрации, навигации
и открытия карточки из `schedule.js` с управляемыми ответами API и минимальным DOM.
Регистрируется настоящий callback перевода, чтобы проверить повторную отрисовку
при смене языка. Отрисовка карточек подменена сбором строк, сетевых запросов нет.

Покрываются полные названия, ID преподавателя, необязательные поля, фильтрация
опасных URL, московское время при ином TZ, недопустимые интервалы, удаление дублей,
сохранение параллельных групп, приоритет ID дисциплины, независимые действия
карточек и переход по известному ID сущности без неоднозначного поиска.
Полный кэш включает даты вне окна таблицы, сохраняет параллельные подгруппы
и не возвращает удалённую исходную запись; пустой снимок остаётся пустым.
Запрос учебного плана использует полное название и дату пары. В серверной выборке
расписания группы её разрешённый ID и подпись сохраняются для модульных, языковых
и совместных занятий, даже если исходная группа пары другая; поля самой пары
остаются неизменными. Реальный пример ПМ23-1 / «Машинное обучение на графах»
проверяет ID 162426 и подпись ПМ23-1. Некорректный ID основной группы не заменяется
ID модуля. В расписании преподавателя/аудитории сохраняются ID и подпись группы
выбранной пары; ID преподавателя/аудитории не принимается за группу.
Переход к другой группе немедленно убирает старый снимок и действия карточек:
фильтр и смена языка не возвращают их ни во время загрузки, ни после ошибки.
Проверяются повторная загрузка без известных границ, принятие только нового
снимка, игнорирование запоздалого ответа и сохранение прежних данных при
неуспешном фоновом обновлении той же сущности.
Проверяются параллельные группы,
другой семестр, неоднозначные ID, несколько форм аттестации и сохранение provenance.
Несовпадение группы, неизвестные формы и ссылки вне HTTPS-домена университета
отвергаются; неизвестное состояние не преобразуется в подтверждённый экзамен.
Проверенная копия PDF принимается только по неизменяемому пути с ID и SHA-256;
тесты проверяют отдельный домен/префикс API, отсутствие повторного `/api` и отказ
от произвольных внешних ссылок, query-параметров и обходов пути.
Серверный маршрут проверяется отдельно в `test_schedule_search_api.py`:
весь семестр, отсутствие upstream-запросов, неизменяемость исходного снимка,
разрешённый ID, различение пустого/отсутствующего/некорректного кэша и rate limit.

```powershell
./.venv/Scripts/python.exe -m unittest tests.test_lesson_details -v
```

Зависимости: стандартная библиотека Python и Node.js в PATH; без Node тесты явно
пропускаются. Сети, API, базы данных и браузер не нужны. Подпроцессы ограничены
20 секундами; файлы не изменяются. Это проверки поведения модели, не замена
визуальной проверки DOM. При переносе функций обновить пути/границы загрузки,
сохранив поведенческие утверждения, а не проверки текста реализации.
## Teacher rating regressions

The Node VM tests also exercise production normalization of separate teacher
arrays and compound names, conservative ID pairing, distinct missing and zero
metrics, wrong-person/source rejection, and independent asynchronous lookups.
Deferred promises prove per-name deduplication, continued loading when another
teacher finishes, cancellation on occurrence change/close, late-response rejection
and retry. The API adapter test verifies encoded names and AbortSignal forwarding.
These require Node; actual dialog layout, focus and RU/EN dark/mobile rendering
remain browser checks.

The desktop timetable regression executes `renderDesktopGrid` with actual RU/EN
dictionaries and switches language between renders. It covers class/day/module
counts, the loaded date range, empty days and missing-range/module metadata;
Russian source course names remain outside translation scope.
