# project.html

Страница GitHub README Matplobbot.

## Основные элементы

Структура заголовка, действий, адаптивного оглавления и статьи; точка входа `/project` из карточки проекта на главной.

## Использование

Открыть `/project`; обновление документа выполняется кнопкой «Обновить».

## Зависимости

project_readme.js, общая навигация/локализация/стили; Marked 15.0.12 и DOMPurify 3.4.16 с SRI.

## Побочные эффекты и сопровождение

CSP разрешает запрос README только к GitHub API и изображения по HTTPS. Страница не исполняет код или инструкции из README. Меняя библиотеки, сохранять SRI, санитизацию и precache.
