Круги становятся плоскостью

В исходной плоскости красный диск и синее кольцо нельзя разделить прямой. Признаковое отображение φ(x, y) = (x, y, x² + y²) поднимает кольцо выше, и между классами появляется горизонтальная плоскость.

Что наблюдать

  • Красный диск имеет r² ≤ 0.30, синее кольцо — r² ≥ 0.90: между ними оставлен зазор.
  • В 2D граница — окружность, поэтому одной прямой разделить классы нельзя.
  • В 3D координата z = x² + y² превращает окружность в сечение плоскости z = c.

Граница применимости

Это фиксированная демонстрация отображения признаков и разделимости заданного набора точек. Здесь не решается задача обучения SVM и не вычисляется оптимальная max-margin гиперплоскость.

φ(x, y) = (x, y, x² + y²),  z = c

Плоскость c выбрана внутри зазора между классами.
