# project_readme.js

Загрузка и безопасный показ README.

## Основные элементы

`load` получает base64 README фиксированного Ackrome/matplobbot; `render` санитизирует HTML, строит якоря/оглавление, разрешает относительные ссылки и добавляет копирование кода.

## Использование

Загружается только на project.html. Успешный README кэшируется в `mpb-readme-v1` на десять минут; при ошибке доступна сохранённая копия.

## Зависимости

GitHub public REST API, Marked, DOMPurify, TextDecoder, clipboard, localStorage.

## Побочные эффекты и сопровождение

Внешний Markdown считается недоверенными данными. Не разрешать javascript URL, обработчики событий, формы или iframe. Ошибки картинок показывают alt-текст. Проверять недоступный GitHub, CDN, кэш и длинный README; UI переводится, исходный документ сохраняет свой язык.
