# project_readme.js

Загрузка и безопасный показ README.

## Основные элементы

`load` выбирает `README.md` или `README.ru.md` по языку сайта и получает base64 через GitHub Contents API фиксированного Ackrome/matplobbot. `fetchDocument` проверяет размер, кодировку, репозиторий и имя файла. `render` санитизирует HTML, строит якоря/оглавление, разрешает относительные ссылки и добавляет копирование кода.

## Использование

Загружается только на project.html. `mpb-readme-v2:en` и `mpb-readme-v2:ru` хранят отдельные копии. Свежая копия используется десять минут; при ошибке доступна более старая. Например, выбор RU в навигации или ссылки «Русский» в самом README загружает русскую версию без ухода со страницы. Ctrl/Cmd+click сохраняет обычный переход в GitHub.

При GitHub 404 для русского файла загружается английский с явным уведомлением. Английский текст не записывается в русский кэш. Смена языка отменяет старый запрос; счётчик запросов дополнительно исключает перезапись новым языком запоздавшим ответом. Ошибки сети и API не выдаются за отсутствие перевода.

## Зависимости

GitHub public REST API, Marked, DOMPurify, TextDecoder, clipboard, localStorage.

## Побочные эффекты и сопровождение

Внешний Markdown считается недоверенными данными. Не разрешать javascript URL, обработчики событий, формы или iframe. Ошибки картинок показывают alt-текст. Проверять переключение RU/EN, быстрые смены языка, недоступный GitHub/CDN, отсутствие русского файла и раздельный кэш. Атрибут lang статьи соответствует языку фактически показанного документа.
