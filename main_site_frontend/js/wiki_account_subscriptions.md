# account_subscriptions.js

Раздел «Расписание и подписки» на `/account`. Содержит список пользовательских
профилей, поиск и создание подписки, входы в общий календарный редактор и ссылки
на добавление/управление подписками в Telegram. Нового хранилища не создаёт.

## Интерфейсы

- `MpbAccountSubscriptions.init(user)` вызывается account.js после проверки
  `/auth/me`: устанавливает пользователя и загружает `/cal/subscription`.
- `MpbCalendarHost` — адаптер для calendar_sync.js. Передаёт пользователя,
  текущую сущность, модули, состояние редактора, `onState`, `onProfileSelected`
  и `openSchedule`. Список страницы обновляется после тех же API-операций,
  которыми пользуется календарь расписания.
- `openProfile` открывает подключение календаря или раскрытые настройки.
  `loadProfileModules` загружает все доступные модули выбранной сущности;
  устаревший ответ предыдущего профиля отбрасывается.

## Использование

Загрузить после frontend_i18n.js и schedule_api.js, **до** calendar_sync.js и
account.js. После авторизации: `MpbAccountSubscriptions.init(user)`.
DOM-контракт — `subscriptions-*` и `subscription-*` в account.html.
Поиск использует `ScheduleApi.searchEntities`, создание — существующий
`POST /cal/subscription/profiles`; изменения/удаление/ссылки выполняет общий
calendar_sync.js. Введённое название не используется как ID: нужно выбрать
реальный результат поиска.

## Зависимости и побочные эффекты

RU/EN `account.subscriptions.*`, account_subscriptions.css, общий календарный
редактор, авторизованный API и публичный API расписания. Приватные ссылки не
помещаются в список или localStorage. Создание календаря не отправляет сообщения
в Telegram. Deep links `web_subscribe` и `web_subscriptions` открывают только
существующие интерактивные сценарии бота; отправка начинается после выбора
пользователя в Telegram.

## Сопровождение

Сохранять общую модель профилей; не копировать редактор и календарные мутации
в account.js. При запросе модулей показывать загрузку, а при ошибке — переход
к расписанию, не подменять все модули уже выбранными. Сохранять стабильные ID
кнопок для восстановления фокуса после перерисовки списка. Не показывать неуспешную
загрузку как пустой список. При смене JWT страницу перезагружает account.js,
а calendar_sync.js дополнительно отбрасывает запоздалые ответы прежней сессии.
Проверять создание, изменение, удаление, пустой список, 401/503, RU/EN и телефон.
