# offline.js

Действия офлайн-страницы.

## Основные элементы

Проверяет CacheStorage для оболочек расписания и Студии, показывает доступные ссылки и действие повторной загрузки.

## Использование

Открыть `/offline`; ссылки появляются только для реально сохранённых оболочек.

## Зависимости

CacheStorage, frontend_i18n, MpbUI, событие online.

## Побочные эффекты и сопровождение

Наличие оболочки не гарантирует наличие личных API-данных. Не показывать безусловные обещания офлайн-доступа. При смене RU/EN переводить и динамический статус.
