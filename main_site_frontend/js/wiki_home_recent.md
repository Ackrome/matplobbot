# home_recent.js

Быстрый возврат с главной.

## Основные элементы

Добавляет ссылки на последнее расписание и последний проект текущей учётной записи; перерисовывается при смене языка.

## Использование

После открытия проекта вернуться на `/`; ссылка использует `/studio?project=ID`.

## Зависимости

MpbUI, frontend_i18n, локальные ключи mpb_schedule_recent_entities и mpb-last-project:<JWT sub>.

## Побочные эффекты и сопровождение

Названия вставляются через textContent, параметры через URLSearchParams/encodeURIComponent. Локальная ссылка не даёт права доступа: API проверяет владельца проекта. При повреждённом или недоступном хранилище блок остаётся пустым.
