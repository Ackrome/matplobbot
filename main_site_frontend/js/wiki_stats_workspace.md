# stats_workspace.js

Разделение административных сценариев.

## Основные элементы

Добавляет режимы состояния сервиса, использования и модулей. Показывает контекстные повтор/сброс вместо постоянной плавающей панели.

## Использование

Открыть `/stats` администратором и выбрать один из трёх режимов.

## Зависимости

stats.js, insights.js, product_ui.css и существующие проверки require_admin в API.

## Побочные эффекты и сопровождение

Только меняет видимость и вызывает существующие загрузчики. Скрытие HTML не является авторизацией. Диагностика доступна постоянно; повтор появляется при ошибке, сброс — в режиме использования.
