# account_subscriptions.css

Оформление списка и поиска подписок внутри `.account-subscriptions` на странице
аккаунта. `body.account-page` связывает `--schedule-*` с общими `--ui-*` цветами,
чтобы тот же календарный dialog корректно работал вне расписания.

## Компоненты и использование

`subscription-row` — сохранённое расписание, `subscription-actions` — кнопки,
`subscription-telegram` — отдельный блок сообщений бота. Поиск использует
`subscription-search-fields` и список кнопок с aria-pressed. Подключается после
product_ui.css и calendar_sync.css в account.html.

## Зависимости, эффекты, сопровождение

Использует тему `.dark` и общие `--ui-*` переменные. Стабильный scrollbar-gutter
предотвращает скачок ширины при открытии модального окна на компьютере. До 600 px
поля поиска становятся вертикальными, кнопки переносятся по ширине блока.
Нет глобального изменения кнопок других разделов аккаунта. Проверять длинные
названия, RU/EN, тёмную тему и 320/390/820/1440 px; не прятать действия удаления
и управления Telegram в неочевидные меню.
