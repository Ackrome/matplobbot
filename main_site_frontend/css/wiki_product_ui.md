# product_ui.css

Общие поверхности интерфейса.

## Основные элементы

Переменные `--ui-*`, классы `.ui-button`, `.ui-card`, `.ui-dialog`, `.readme-*`, `.plan-*` и адаптивные дополнения страниц. Общие цвета, границы, фокус, размеры элементов и тёмная тема.

## Использование

Подключать после Tailwind и локальных стилей страницы. Например `<link rel="stylesheet" href="/css/product_ui.css?v=20261009-6">`.

## Зависимости

Tailwind, HTML страниц, классы `.dark`, `.studio-page`; некоторые старые стили расписания вставляет schedule_ux.js.

## Побочные эффекты и сопровождение

Меняет внешний вид всех страниц; меню переключается на компактное ниже 1280 px. Проверять 390/820/1440 px, длинные RU/EN подписи и переходы CSS. Не переопределять `.hidden` через display без отдельного правила.

В таблице расписания `.schedule-timeline-card .lesson-table-meta` размещает аудиторию и преподавателя через 8 px после текста, убирая растягивающий `margin-top: auto`. Селектор учитывает позднее добавление стилей schedule_ux.js. Высоту строки и координаты занятий задаёт общий `TABLE_SLOT_ROW_HEIGHT_PX` в schedule.js; не уменьшать только CSS-высоту строки отдельно от расчётов времени.

В двух параллельных колонках скрывается плашка модуля, название занимает до двух строк, а метаданные используют всю ширину над кнопкой действий. Короткие занятия показывают время начала и окончания в две строки рядом с кнопкой; их заголовок не должен наследовать трёхстрочное ограничение узких карточек из schedule_ux.js. Полные сведения доступны по нажатию на название.
